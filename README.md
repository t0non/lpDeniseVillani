# Site da Dra. Denise Villani de Carvalho

Página original: https://drjoaocardiologista.com.br/

O arquivo `dist/index.html` adapta o layout original do Elementor à Dra. Denise. Estilos, scripts, imagens e fontes estão em `dist/assets/`. A imagem da Denise foi fornecida pelo usuário. O Google Tag Manager original foi removido.

Fonte dos dados profissionais: https://www.doctoralia.com.br/denise-villani-de-carvalho/cardiologista-medico-clinico-geral/belo-horizonte (consultada em 19/10/2026). Agendamentos direcionam para esse perfil. O telefone exibido é o contato intermediado pela Doctoralia, não um WhatsApp confirmado. Os depoimentos do médico anterior foram removidos, assim como seu programa e serviços não confirmados para a Denise.

## Executar

Execute `npm start` e abra http://localhost:5173.

## Editar e verificar

Edite `dist/index.html` e `dist/denise.css` para atualizar o site. Os arquivos em `dist/` estão prontos para hospedagem estática. Para atualizar os depoimentos, edite `testimonials.json` e execute `python render_testimonials.py`. Para verificar os dados e recursos locais, execute `python verify_site.py`.

Requer Python 3 para executar o servidor local e os scripts auxiliares. Não exige instalação de dependências.
